# AntiCrash — Minecraft 1.16.1

- **Status:** Port in progress; no usable Mod or Supervisor JAR is available.
- **Minecraft:** 1.16.1
- **Java baseline:** 8 or newer.
- **Fabric Loader:** Compatible version not yet established.

The version-specific port is incomplete. Minecraft runtime capture and restore adapters, mixins, and full baseline integration are not ready. Do not install this directory as a released server mod or use it to recover a valuable world.

AntiCrash is intended as a server-side Fabric mod. When a version is released, its checkpoint data must only be used with the same Minecraft version. Keep independent world backups.
