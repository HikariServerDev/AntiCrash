# Changelog

## Unreleased - 1.0.1 readability cleanup

- 復旧前チェック、保存エンジン判定、診断ログの組み立て、FakePlayer保存要件を、小さな責務別処理へ抽出。設定値、保存形式、権限、World変更・再開の順序は維持。
- 元の1.0.1実装との新旧比較テストを追加。判定結果、拒否理由、診断文字列の一致を検証。変更対象外のメソッドとリソースも比較。
- 1.16.1の移植は依頼により中断し、CIの移植検証から除外。既存ソースは保持する。

## 1.0.1 - 2026-11-02

- aomonaさんのForkから共通ソース化の設計と完全な監査対象の考え方を採用。版別フォルダー・Minecraft API差分・ビルド設定を維持し、同一コードとSupervisorを共通化。
- Javaコードの書式を全版で統一。保存範囲の監査は構文解析に変更し、コメント・改行では検査をすり抜けないよう強化。
- バージョンを1.0.1へ更新。Checkpoint形式・設定初期値・権限・復旧の実行処理は変更しない。1.0.0とのバイトコード比較はデバッグ情報と版表記のみを正規化して検証。
- GitHub Actionsへ全ビルド対象・旧版アダプター・重複ソース・書式の検証を追加。1.16.1は引き続き未完成で配布不可。

## Unreleased - 2026-10-30

- 全版へFakePlayerのcheckpoint UUID復元・名前/UUID衝突の事前拒否・UUID不一致診断を反映。各版の実際のプロフィールキャッシュAPIに適合し、通常のログイン/認証/キャッシュ内容は変更しない。
- 新Carpetの非同期プロフィール取得は復旧scope内だけ保存済みプロフィールで完了し、その完了済みプロフィールの生成だけServer thread上で即時登録。通常のCarpetの非同期取得/Executorは維持。Vector形式の生成引数にも対応。未知の生成APIやUUID不一致は引き続き復旧を拒否する。
- Scope分離・後片付け・非同期完了・版別キャッシュのbytecode契約を実Server不要のテストで検証。1.16.1は引き続きPORT_IN_PROGRESSで配布不可。
